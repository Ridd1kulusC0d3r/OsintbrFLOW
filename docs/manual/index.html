OSINT Brasil Flow
Conecte os fatos. Preserve a origem.

Um laboratório de investigação em fontes abertas que roda no seu computador. Você informa um CNPJ, um CEP ou um código de município, o programa consulta fontes públicas brasileiras e guarda cada resposta como evidência, com data, endereço de origem e uma impressão digital (SHA-256).

  • Sem conta e sem chave de API
  • Roda só no seu computador
  • Windows · macOS · Linux · Colab
  • Pessoa física: recusado

1O que é, para que serve e o que não faz

O OSINT Brasil Flow (também chamado OsintbrFLOW) é uma ferramenta de investigação empresarial e territorial. Ele parte de um identificador público, segue um percurso curto de consultas e mostra o resultado como um grafo: caixas (entidades) ligadas por setas (relações). Cada caixa sabe de onde veio.

Aceita

  • CNPJ de empresa (14 posições, numérico ou o novo formato alfanumérico)
  • CEP (8 dígitos)
  • Código IBGE de município (7 dígitos, ex.: 3106200 = Belo Horizonte)

Para que serve

  • Conferir o cadastro público de um fornecedor ou parceiro
  • Ligar empresa → CEP → município oficial, com a origem de cada passo
  • Repetir a consulta depois e ver o que mudou
  • Exportar um pacote que outra pessoa consegue conferir
  • Aprender o método com um caso fictício, sem internet

O que NÃO faz

  • Não consulta CPF nem pessoa física. É recusado de propósito, antes de qualquer consulta, e o valor não é gravado
  • Não conclui culpa, fraude ou risco
  • Não diz onde uma pessoa mora: CEP não prova residência
  • Não automatiza todo o Atlas: só 3 fontes são consultadas pelo programa
  • Não substitui cadeia de custódia jurídica

Não exponha à internet. O laboratório não tem login. Ele só aceita conexões do próprio computador (endereço 127.0.0.1) e não há opção para mudar isso. Não tente publicá-lo com redirecionamento de porta, túnel ou servidor web: qualquer pessoa que alcançasse o painel veria e alteraria seus casos. Para uso em equipe existe outro caminho, com contas individuais: veja Hospedar para uma equipe.

Leitura correta dos resultados. Um vínculo é uma observação reportada por uma fonte, não uma acusação. O hash mostra que o conteúdo não foi alterado depois da coleta; ele não comprova que a informação é verdadeira nem quem é o autor. Fonte fora do ar não significa que o registro não existe.

2Instalação passo a passo

Escolha o seu sistema. Não precisa instalar Python, Node, criar conta nem pegar chave de API (exceto no caminho pipx, que é para quem já usa Python).

Onde baixar. Os pacotes do aplicativo ficam na página de Releases do projeto no GitHub, junto com o arquivo SHA256SUMS.txt. Até a data deste manual ainda não havia versão publicada: a primeira aparece quando a equipe criar uma versão (tag v*). Enquanto isso, o caminho sem instalação é o Google Colab.

Cada sistema tem um arquivo próprio, com o nome no formato OsintbrFLOW-0.2.0-<sistema>-<arquitetura>.zip (por exemplo …-windows-x64.zip, …-macos-arm64.zip, …-linux-x64.zip). Dentro do .zip há uma pasta com:

Windows

  1. Baixe o arquivo …-windows-x64.zip da página de Releases.

  2. Extraia o .zip inteiro. Clique com o botão direito no arquivo → Extrair tudo… → escolha uma pasta (por exemplo, Documentos). Não abra o programa de dentro do .zip.

  3. Na pasta extraída, dê dois cliques em Abrir OsintbrFLOW.bat.

  4. Aviso do SmartScreen (só na primeira vez): aparece “O Windows protegeu o computador”. Clique em Mais informações e depois em Executar assim mesmo.

  5. Abre uma janela de texto (o “motor” do laboratório) e, em seguida, o painel: numa janela própria ou no seu navegador. Deixe a janela de texto aberta enquanto usa o painel.

Para encerrar: feche o painel e depois a janela de texto (ou pressione Ctrl+C nela).

Seus casos ficam em %APPDATA%\OsintbrFLOW (ex.: C:\Users\voce\AppData\Roaming\OsintbrFLOW).

macOS

O pacote é para Mac com Apple Silicon (M1, M2, M3…: arquivo …-macos-arm64.zip). Não há pacote .app nem ícone próprio: o programa é aberto pelo lançador Abrir OsintbrFLOW.command, que usa o Terminal.

  1. Baixe o arquivo …-macos-arm64.zip da página de Releases.

  2. Extraia com dois cliques no .zip (o Finder cria a pasta). Mova a pasta para Documentos, se quiser.

  3. Primeira vez: dê dois cliques em Abrir OsintbrFLOW.command. O macOS bloqueia e avisa que o app é de um desenvolvedor não identificado: feche o aviso.

  4. Vá em Ajustes do Sistema → Privacidade e Segurança, role até o fim e clique em Abrir Mesmo Assim ao lado do aviso sobre o OsintbrFLOW. Confirme com sua senha e abra de novo. (Antes do macOS 15 Sequoia, também dava para clicar com o botão direito → Abrir; no macOS 15 esse atalho não existe mais.)

  5. Abre uma janela do Terminal e, em seguida, o painel. Deixe o Terminal aberto enquanto usa o painel. Das próximas vezes, basta dar dois cliques no lançador.

O lançador remove sozinho a marca de “arquivo baixado da internet” (quarentena) da pasta do aplicativo; sem isso o macOS bloquearia cada biblioteca interna separadamente.

Seus casos ficam em ~/Library/Application Support/OsintbrFLOW.

Linux

  1. Baixe o arquivo …-linux-x64.zip e extraia o .zip inteiro.

  2. Dê dois cliques em abrir-osintbrflow.sh. Se o gerenciador de arquivos perguntar, escolha Executar (ou “Executar no terminal”).

  3. Pelo terminal, o equivalente é:

    cd OsintbrFLOW-0.2.0-linux-x64
./abrir-osintbrflow.sh

  4. O painel abre no navegador (ou numa janela própria, se o sistema tiver suporte). Deixe o terminal aberto; Ctrl+C encerra.

Seus casos ficam em ~/.local/share/osintbrflow.

pipx — para quem já usa Python

Se você já tem Python 3.12 ou mais novo e o pipx, pode instalar o pacote Python (arquivo .whl) anexado à mesma página de Releases. O pacote ainda não está no PyPI: o comando aponta para o arquivo baixado.

  1. Baixe osintbrflow-0.2.0-py3-none-any.whl da página de Releases.

  2. Instale e abra:

    pipx install ./osintbrflow-0.2.0-py3-none-any.whl
osintbr

  3. Opcional, janela própria em vez do navegador: instale com o extra janela (pywebview) e use osintbr --janela.

    pipx install "./osintbrflow-0.2.0-py3-none-any.whl[janela]"
osintbr --janela

  4. Se o comando não for encontrado, rode pipx ensurepath e abra um terminal novo. Na pasta pipx do .zip há lançadores de dois cliques que chamam o osintbr instalado assim.

Google Colab — sem instalar nada

Tudo roda numa máquina temporária do Google. Bom para primeiro contato, aula ou demonstração. Precisa de uma conta Google.

  1. Abra o notebook no Colab e clique em Conectar (sessão CPU; não precisa GPU).

  2. Selecione Ambiente de execução → Executar tudo e aceite o aviso de notebook do GitHub.

  3. Aguarde a célula 1 (Preparar): 3–8 minutos na primeira vez. A célula 2 (Iniciar) leva segundos.

  4. Use o painel que aparece na célula 3. Comece em Explorar caso demonstrativo.

  5. (Opcional) A célula 4 (Autoteste) roda os testes e confere se BrasilAPI, ViaCEP e IBGE respondem naquele momento.

Os dados duram enquanto o ambiente do Colab existir: exporte o que quiser guardar. Para encerrar, use Ambiente de execução → Desconectar e excluir ambiente de execução. Não compartilhe capturas de uma sessão ativa: o painel usa uma chave temporária por sessão.

Conferir que o arquivo é o oficial

O aplicativo é gratuito e ainda não tem assinatura digital paga da Microsoft ou da Apple; por isso os avisos acima são esperados. Só libere o programa se baixou da página oficial de Releases. Para conferir, compare o SHA-256 do .zip com a linha correspondente em SHA256SUMS.txt:

Windows (PowerShell)

Get-FileHash .\OsintbrFLOW-…zip

macOS (Terminal)

shasum -a 256 OsintbrFLOW-…zip

Linux

sha256sum OsintbrFLOW-…zip

3Como funciona

O percurso: CNPJ → CEP → município

O fluxo principal, Empresa → território, faz três consultas em sequência. A resposta de cada uma fornece a chave da seguinte. Cada resposta vira uma evidência.

Há quatro fluxos prontos. Você também pode mandar parar antes (“Parar após N etapas”).

5Tutorial: o caso demonstrativo

O caso demonstrativo usa uma empresa inventada (“AURORA PESQUISA LTDA · FICTÍCIA”, CNPJ 11222333000181, que só é usado como exemplo de formato) e não acessa a internet. Faça uma vez antes de usar fontes reais. Leva uns cinco minutos.

Passo 1 — Abrir o caso

Na tela inicial, clique em Explorar caso demonstrativo (ou em Explore o laboratório, no canto inferior esquerdo). O programa cria o caso “Operação Aurora · laboratório” e executa o fluxo Empresa → território com dados sintéticos.

Passo 2 — Clicar numa entidade e ver a origem

Clique na caixa verde da empresa. À direita abre o painel Entidade observada com tudo o que a fonte devolveu.

Role o painel até o fim para ver de onde aquilo veio:

Passo 3 — Ler as evidências

Clique na aba Evidências. Há uma evidência por consulta. Clique numa delas para abrir.

Passo 4 — Repetir e ver as mudanças

Sem mudar nada no formulário, clique de novo em Executar fluxo. Depois abra a aba Mudanças. Com o mesmo identificador, modo e fluxo, o programa compara campo a campo com a coleta anterior.

Falhas não contam como desaparecimento: se uma coleta falhar ou vier parcial, o programa não relata campos “removidos”.

Passo 5 — Exportar

Continue para a seção 7 e exporte este caso. Ele é ótimo para treinar a verificação do pacote.

7Relatórios: exportar e verificar

O relatório do OSINT Brasil Flow é um pacote de evidências em JSON: um arquivo que guarda o caso inteiro e pode ser conferido em outro computador. Os três botões ficam no canto direito da barra de abas.

Exportar evidências (pacote JSON)

Arquivo osintbrflow-<caso>.json com:

  • o caso (nome e finalidade);
  • todas as coletas, com identificador, modo, etapas, situação e data;
  • cada evidência: endereço, horário, resposta recebida e SHA-256;
  • o grafo e as mudanças de cada coleta;
  • o hash encadeado de cada coleta, o hash final (head_hash) e um checksum do pacote.

Exportar grafo (para o Flowsint)

Arquivo flowsint-graph-<coleta>.json só com a coleta aberta: nós tipados (BrazilCompany, BrazilCEP, BrazilMunicipality), relações e a referência de evidência de cada um.

Serve para continuar a investigação no Flowsint completo, pelo Importar JSON da investigação nativa. Não há sincronização automática entre os dois.

Verificar um pacote

No painel: clique no primeiro ícone (Verificar pacote) e escolha o arquivo .json exportado (limite 15 MB). Se nada foi alterado, aparece “Integridade verificada”.

Pela linha de comando (para quem tem o código-fonte; só usa Python):

python scripts/verify-bundle.py osintbrflow-<caso>.json

Resposta real para o pacote do tutorial:

{
  "valid": true,
  "errors": [],
  "runs": 2,
  "note": "Integridade local; hash não comprova veracidade, autoria ou cadeia de custódia jurídica."
}

O comando termina com código 0 quando o pacote está íntegro e 1 quando não está. Se alguém alterar um caractere de uma resposta, a verificação falha e diz onde.

O que o hash prova e o que não prova. Prova que o conteúdo do pacote não mudou depois da coleta. Não prova que a fonte estava certa, quem é o autor, nem impede que alguém que controle todo o armazenamento reescreva tudo e gere hashes novos. Não é cadeia de custódia jurídica.

Como desinstalar

  1. Feche o painel e a janela de texto.

  2. Apague a pasta onde você extraiu o .zip. (Pacote Python: pipx uninstall osintbrflow.)

  3. Se quiser apagar também os casos, apague a pasta de dados indicada acima. Isso é definitivo: exporte antes o que quiser guardar.

9Glossário

OSINT
Inteligência de fontes abertas (Open Source Intelligence): investigação feita só com informação pública e acessível legalmente.
CNPJ
Cadastro Nacional da Pessoa Jurídica: o número de uma empresa na Receita Federal. 14 posições; os dois últimos são dígitos verificadores. O programa aceita também o formato alfanumérico novo.
CPF
Cadastro de Pessoas Físicas. Recusado pelo programa, de propósito.
CEP
Código de Endereçamento Postal, 8 dígitos. Indica uma área postal, não a casa de alguém.
IBGE
Instituto Brasileiro de Geografia e Estatística. Cada município tem um código IBGE de 7 dígitos (Belo Horizonte = 3106200).
BrasilAPI · ViaCEP
Serviços públicos e gratuitos usados pelo programa para o cadastro de CNPJ e para o CEP. São intermediários: a atualização dos dados depende deles.
Caso
Uma investigação com nome e finalidade. Guarda todas as coletas feitas para ela.
Finalidade
O motivo declarado da investigação. É obrigatória e vai junto no pacote exportado.
Fluxo (percurso)
A sequência de consultas a fazer a partir de um identificador, por exemplo CNPJ → CEP → município.
Semente
O identificador que você digita para começar o fluxo.
Coleta
Uma execução de um fluxo num caso, num momento. Pode ser completa, parcial ou falhar.
Evidência
A resposta de uma fonte guardada exatamente como chegou, com endereço, horário e hash.
Proveniência
A origem rastreável de uma informação: de qual fonte, por qual endereço, quando e com qual versão do programa.
Hash / SHA-256
Uma “impressão digital” de 64 caracteres calculada sobre um conteúdo. Se um único caractere mudar, o hash muda totalmente. Mostra alteração; não mostra veracidade.
Hash encadeado
Cada coleta inclui o hash da anterior. Mexer numa coleta antiga quebra a corrente e a verificação acusa.
Grafo
Desenho de caixas (entidades, ou nós) ligadas por setas (relações).
Entidade
Uma coisa observada: empresa, CEP ou município.
Pacote de evidências
O arquivo JSON exportado com o caso inteiro, pronto para ser verificado.
JSON
Formato de arquivo de texto estruturado, legível por pessoas e programas.
Dados sintéticos
Dados inventados para treino. Nunca devem ser apresentados como resultado real.
Atlas de fontes
Catálogo de 1.171 entradas: 3 conectores reais e 1.168 referências de pesquisa manual (do OSINT Brazuca), não testadas individualmente.
127.0.0.1 (localhost)
O endereço do próprio computador. Só programas da sua máquina chegam nele.
Porta
Número que identifica um serviço no computador (padrão 8000).
SmartScreen · Gatekeeper
As proteções do Windows e do macOS que avisam sobre aplicativos sem assinatura digital paga.
pipx · wheel (.whl)
Ferramenta para instalar programas Python isolados, e o formato de pacote Python que ela instala.

O que ainda não foi verificado

  • Windows e macOS: build e teste de fumaça só no CI (.github/workflows/release.yml); não executados no ambiente de validação. Inclui o ícone .ico, os lançadores .bat e .command e o fluxo de Release com SHA256SUMS.txt.
  • Em nenhum lugar ainda: a janela própria aparecendo de fato (WebView2 no Windows, WebKit no macOS); os avisos SmartScreen e Gatekeeper exatamente como descritos aqui; o duplo clique nos lançadores em cada sistema. Os aplicativos não são assinados e o macOS não tem pacote .app.
  • Google Colab real: a sessão hospedada não foi executada pela validação; falta anexar o resultado do autoteste de uma sessão real.
  • Fontes reais no ambiente da revisão mais recente: bloqueadas pela rede. (Uma validação anterior, de 2026-10-09, completou o percurso real CNPJ 00000000000191 → CEP → município com três evidências.)
  • Hospedagem para equipe: nenhuma implantação real numa VPS foi executada; os arquivos foram validados de forma estática.

O laboratório deste manual é de usuário único e não deve ser exposto à internet. Para equipe, hospede o fork completo (com contas individuais) seguindo o guia docs/brasil/DEPLOY.md: VPS Linux com Docker, HTTPS automático, cadastro público fechado por padrão, backups com ensaio de restauração, lista de conferência de segurança e um roteiro mínimo de LGPD.
